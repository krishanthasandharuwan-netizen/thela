READY FOR NETLIFY STATIC HOSTING

Upload the provided .ZIP file as a manual deploy in Netlify, or unzip it and drag the folder (with index.html at its root) to https://app.netlify.com/drop .

No npm, React, Node.js, API keys, build commands or paid services required.

FILES:
 index.html      - Website homepage
 styles.css      - Full responsive Netflix-inspired styling
 script.js       - Photo cards, local favorites, trip date, budget calculator, modals, menu
 credits.html    - Photo attributions and copyright information
 assets/         - Locally bundled hero art, Thela photo, WhatsApp QR, favicon

WHAT WORKS:
 - Official WhatsApp join invitation button + matching QR
 - Interactive destination cards with detailed popups and Google Maps shortcuts
 - Tap hearts to save favorite destinations on the visitor's own device
 - Proposed two-day itinerary with day tabs
 - Select preferred trip date on the visitor's own device
 - Adjustable budget estimator (sample figures ONLY)
 - Copy trip picks and WhatsApp invite link
 - Responsive desktop and mobile navigation

IMPORTANT:
 - No fixed group trip date, hotel, departure city, cost or booking were provided,
   so the itinerary and numbers are EXAMPLES, NOT CONFIRMED ARRANGEMENTS.
 - Saved date, saved places and budget values do NOT sync between different people.
   Discuss the final plan in WhatsApp. A shared voting system needs a backend.
 - Actual photographs of the named destinations load from Wikimedia Commons on the live website.
   The locally bundled background is an AI-generated artistic image; the local website
   still has a working scenic background if external images are not available.
 - The personal photo is bundled locally; make sure you have consent before publishing.
 - The group invitation URL is PUBLIC on this site. Anyone with the URL can request access.
 - No affiliation with Netflix. Brand identity is THELAFLIX, a fan-made original trip site.
